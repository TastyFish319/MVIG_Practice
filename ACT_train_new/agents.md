# agents.md — ACT_train_new 开发约定

本文件适用于本工程的全部后续开发。先更新约定，再修改与约定冲突的实现。

## 1. 目标与范围

- 提供完整、独立、可复用的 ACT 数据预处理、训练、验证、评测、报告工程。
- 本地在本目录开发；未来整个目录复制到 Linux 服务器的 `output/` 下运行。
- 保留现有 ACT 的模型和数据兼容性。
- 不在运行时 import SuperInference、Pi-train-new、旧 ACT 工程；不依赖它们的环境注册脚本。
- 不修改旧工程、已有数据和权重；不因整理工程自动启动正式长训练。
- 用户已选择：保留 LeRobot 0.4.4 ACT 与 v2/v3 语义，重构外围工程。

## 2. 不可违反的数据契约

| 项目 | 约定 |
|---|---|
| 观测位置 | 只读 follower；基础状态 `[左6关节, 左夹爪, 右6关节, 右夹爪]`，14 维 |
| 观测图像 | 左右腕 RGB；保持比例缩放补黑至 256×256；不凭空补第三路相机 |
| 默认动作 | 右臂 leader 6 关节 + 夹爪，7 维 |
| 时间 | 20Hz；chunk=32；第 k 项对应观测后 `(k+1)/20` 秒 |
| 关节标签 | `leader_right[t+1+k] - follower_right[t]`；整块共用当前观测为基准 |
| 夹爪标签 | leader 的绝对开度，不做相对量；禁止以 follower 接触后开度代替命令 |
| 历史速度开关 | 不含速度：14 维；含速度：追加右臂7维 `(s[t]-s[t-2])/0.1`，共21维 |
| 历史边界 | 每条 episode 前两帧速度补零；不跨 episode、不读未来 |
| 数据划分 | 整条 episode 划分；审核通过才使用；划分清单固定且可复现 |
| 归一化 | 只用训练集；相对动作统计按合法完整chunk计算；float64、std下限1e-3 |
| 尾部窗口 | 训练只用完整32步；评测尾部只对仍有真实目标的位置计分 |
| 导出契约 | 保存官方模型/processor全部文件及 act_action_contract.json；速度版另存 act_observation_contract.json |

数据集存绝对未来 leader 标签，训练适配层按每个观测起点生成相对chunk，避免预处理时误用不同基准。

## 3. 技术与目录

- Python 3.12；LeRobot 0.4.4；PyTorch/torchvision 版本参考服务器实际环境并单独声明CUDA安装方法。
- 复用官方 ACT、数据写入/读取 API、归一化处理器和优化器，不重写模型算法。
- 多卡使用 Accelerate + torchrun；1/2/4 卡；训练与自动评测使用同一可见设备集合。
- 策略与视觉骨干可分别设置初始 lr、StepLR 开关、间隔、gamma。
- rich 终端；CSV + TensorBoard + PNG；自包含离线 HTML；轻量 statistics.zip。

```text
acttrain/      唯一Python业务包；按data/model/training/evaluation/cli拆分
scripts/       一键启动脚本
configs/       严格校验的默认配置与示例，不含机器绝对路径
docs/          中文流程、环境、调参、兼容性、来源、验收记录
tests/         数据契约、失败路径、模块集成测试
raw_data/      原始episode与审核记录（不进版本管理）
dataset/       完整数据集与划分/追溯信息（不进版本管理）
runs/          每次训练、评测、报告（不进版本管理）
```

## 4. 开发与验收

1. 中文回复、中文文档、中文终端提示；解释概念时先给直观例子。
2. 每完成一个模块更新 changelog.md：改了什么、为什么、验证结果与未验证项；列表优先。
3. 用户2026-11-05最新要求：全部实现完成后集中做最后验收；开发中不逐模块或逐函数执行测试。修复验收发现的实际失败后只复验受影响项。
4. 不把假模型测试写成真实 ACT 训练验证；区分本地CPU、服务器单卡、真实数据、多卡验证。
5. 已有输出拒绝覆盖；预处理先写 `.partial`，成功后同文件系统原子发布。
6. 后台长任务有日志、PID和原子status.json；失败不得发布完整排名或完成状态。
7. 参数未知/无效、审核不一致、契约缺失、设备不足应尽早报错，不静默回退。
8. 首次新工程使用小样本/短训练验收；仅使用明确空闲GPU，不能停止别人的进程。
9. 依赖变更同步 pyproject.toml、requirements与环境文档；新环境安装不修改已有act/pi_fish环境。
10. 不自动git提交、推送、发布或覆盖服务器 `output/ACT`；成果放本工程。

## 5. 兼容性与质量

- 保存现有核心契约；结构整理不宣称所有训练随机数和数值结果逐位相同。
- 默认保留每个ACT checkpoint，支持精简保留策略；不套用Pi大权重的限制。
- 检查旧数据集manifest和validation记录后才导入；拒绝旧follower标签数据。
- 夹爪软下限只作用于可选推理后处理；原始预测指标必须保留，不能靠过滤美化评分。
- 夹爪开度不等于夹持力，滤波不承诺防过载；由部署方另行标定并控制硬件限制。
- 不复制数据、权重、缓存、日志、服务器账号/绝对路径和内部审核文件到发布包。
- 本轮暂不开源、不整理许可证声明、不提供下载命令；保留必要技术来源记录，质量按可复用独立工程要求执行。
- 离线误差和夹爪状态指标不是机器人任务成功率，不用验证集调参后声称独立测试效果。
