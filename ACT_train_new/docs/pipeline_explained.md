# 从录制数据到ACT模型

## 1. 审核与分集

MCAP是带时间戳的消息容器，关节、夹爪和相机各自发布消息。审核JSON记录哪些episode被人工通过，以及当时原文件的SHA256指纹。预处理先确认两份审核记录属于同一任务、通过名单完全相同，文件内容未变化。

划分以整条episode为单位：一段演示不会同时进入训练和验证。默认把按编号排序的episode分段，用固定seed在每段抽一条作验证，以覆盖采集顺序；这不是按物体位置或任务难度分层。界面先显示验证编号，再由操作者确认。旧数据引用保留原split。

## 2. 时间与图像

20Hz意味着每50ms一个观测点。各流只取不晚于该点的最近消息；消息过旧（默认超过100ms）会拒绝处理，不能用未来帧补过去。左右腕JPEG解码成RGB，等比例缩放并补黑边到256×256，写为无损图像；不会生成没有采集过的头部视角。

数据集有两个LeRobot目录train/val。trace保存原始数值与时间戳，manifest记录源文件、episode映射、划分、相机与动作约定，provenance保留审核和参数。先写.partial并由官方读取器核对，再发布为可训练数据集。

## 3. 标签为什么这样构造

输入位置都来自从臂：它表示机器人当前真正到达的位置。输出目标来自主臂：它表示人的操作意图。

```text
当前follower角度 = 1.0 rad
未来leader角度 = [1.2, 1.3, 1.1]
训练相对标签    = [0.2, 0.3, 0.1]
推理还原        = 当前follower + 每个预测相对量
```

整块共用当前观测，不能把第二步减第一步。第一个目标在观测后50ms，32步覆盖未来1.6秒。数据集保留绝对leader标签，由训练采样适配层针对每个chunk起点计算相对量。

夹爪保留主臂绝对开度：主臂0表达闭合意图，从臂夹到物体后停在较大开度是接触结果，不能把它解释成操作者要张开。可选软下限把过小预测平滑映射至指定floor，默认关闭；参数需按物体和夹爪标定。它不是力控制，原始预测指标始终保留。

## 4. 速度输入

不含速度：14维左右臂位置；含速度：增加右臂7维历史速度，共21维。

速度公式为`(follower[t]-follower[t-2])/0.1`，只看过去100ms，每episode前两帧补零。预处理将它存入trace；旧数据训练时可以按同公式生成。它可能帮助辨别运动方向，也可能使模型过度依赖惯性，应该在相同split和样本预算下做有/无速度对照。

## 5. 模型与优化

图像经过ResNet18提取视觉信息，关节状态和视觉特征送入Transformer，一次输出32×7的动作块。ACT使用CVAE：训练时可看示范动作编码动作风格，loss由归一化动作重建L1和10倍KL项组成；推理时不提供未来示范，使用prior latent。

使用官方AdamW与两组参数：策略部分、视觉骨干。两组可以分别设置lr与StepLR，默认都不衰减。启用后，完成N次更新的下一次学习率为`initial_lr * gamma ** (N // step_size)`；间隔不是epoch，不暗中按GPU数缩放。

归一化只用训练数据。状态统计与相对action统计使用float64；近静止维度的std至少1e-3。相对动作统计包括所有合法32步窗口。训练排除不完整尾窗口，避免用重复填充的尾部当真实动作。

## 6. 训练曲线与评测

- posterior训练L1：训练时的重建误差；训练总loss还包含KL。
- train-prior / val-prior：同一权重分别在训练/验证episode上只用观测推理，可直接对照。默认按stride16取窗口，包含最后合法窗口。
- CSV实时写入，TensorBoard实时查看，结束后保存PNG与离线HTML。
- 验证loss选出best_validation；最终评测另用固定seed从val选至多8条，所有权重使用相同清单。
- 每帧预测完整32步；尾部无真值部分不计误差。曲线展示第一步预测与每4步拼接的预测，并与leader标签及follower实测叠加。

兼容评分：0.40×前4步MAE + 0.25×完整chunk MAE + 0.20×中位误差 + 0.15×最大误差。各轴除以绝对action训练std，六关节均值占80%、夹爪占20%，然后episode等权。旧评分的scale与训练用相对action std不同，特意保留以保证排行口径可比。原始rad/deg与夹爪误差分开显示，附P95、RMSE和夹爪F1诊断。

多卡训练采用DDP同步梯度；多卡评测按checkpoint分配独立worker。权重数量少于卡数时实际worker数减少，记录请求与实际数量。任一worker失败不发布完整排行。

只有相同split、选样、尺度、精度和评分版本的分数能直接比较；验证集用于选模型，离线误差不能代替新场景或真机任务成功率。
